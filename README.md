## Overview
A bespoke digital experience showcasing the rarest luxury villas, mansions, and penthouses in Dubai. Features interactive 3D WebGL location maps, smooth cinematic video presentations, and responsive typography.

## Features
- **Interactive 3D Location Map:** Real-time WebGL canvas map of Dubai landmarks and residences.
- **Cinematic Visuals:** Self-contained high-definition video backgrounds with fluid hardware-accelerated playback.
- **Bespoke Typography:** Self-hosted editorial fonts with optimized web font rendering.
- **Zero External Dependencies:** 100% self-hosted assets, scripts, and media.

## Getting Started

